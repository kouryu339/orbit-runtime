# v0.4.8-beta.3 — Structured plans and authorized local search

## Changes since Beta.2

- Agent-owned structured execution plans with stable step IDs, optimistic revision checks,
  cancellation, complete state events and snapshot restoration. Active plans cannot be
  silently overwritten. Model context receives the current structured plan, not repeated
  full Markdown details. Legacy Markdown plans remain readable.
- Lit collapsible plan card: step states, completion progress, focused-agent isolation,
  stale-revision protection and explicit null clearing. Update the Lit package from this tag;
  native archives alone do not update a host's frontend bundle.
- Pure `SplitNode` / `split(value, separators)` supports literal multi-character delimiters,
  longest-match precedence, Chinese separators and preserved empty fields. Empty delimiters
  are rejected. Example: `split("aa-c,i", ["-", ","])` returns `["aa", "c", "i"]`.
- Native AI-only `Grep`: host-authorized local directory capabilities, literal/regex search,
  content/file/count modes, configurable budgets, concurrency control, traversal/junction
  rejection and explicit partial-result reporting. No shell or external rg dependency.

## Retained fixes from Beta.2

- Streaming empty tool IDs/names no longer overwrite valid first-fragment values;
  conflicting nonempty IDs are rejected.
- RPC endpoint `to_ai_max_chars` is configurable (default 600; 0 disables that truncation).
  This is not a new Beta.3 fix. Native Grep bypasses the RPC summary wrapper.

## Host integration

- ABI remains 1.3. Update native binaries and SDK release metadata together; verify SHA256.
- Persist `conversation.state_delta` including `agent_plan.set` alongside ledger data and
  restore those deltas on snapshot import. Preserve plan_id, revision, steps and timestamps.
  Treat `plan: null` as a clear operation. New plan updates/finish require plan_id and revision.
- For custom UI, route plan state by agent_id; background-agent plans must not replace the
  focused agent's card. Lit source and generated dist are in this release's Git tag.
- Add `grep.roots` to resources registration before Runtime start. No roots means no file
  access. Root IDs are selected by AI; actual directory paths are chosen only by the host.
  JSON-only registration should use absolute paths. Resource-file-relative paths are supported.
- Built-in thinking skills include Grep; custom skills must list it. Grep is not a Workflow
  node and cannot be called from scripts. Normal tool permission policy still applies.
- Resource registration freezes at startup. Restart Runtime and recreate conversations to
  change grants. Do not restore filesystem grants from model-controlled snapshots.
- Respect complete/truncated/reason and line_truncated; partial results do not establish
  absence. Count means matching lines. Only nonhidden, nonignored UTF-8 text is searched.
- Configure timeout, output/file/pattern/regex/entry budgets and concurrency for your host.
  OS IO cancellation is cooperative, not a hard process kill. Search is not an OS sandbox;
  do not grant hostile directories with sensitive hard links or special files.
- Search results may enter tool logs: apply appropriate access and retention policies.
