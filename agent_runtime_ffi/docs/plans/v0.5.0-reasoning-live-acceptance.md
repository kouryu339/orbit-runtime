## 已验证

- 三种范式的默认（不配置 reasoning）、low、high：非流式和流式均完整完成，算术题结果一致。
- 额外档位 minimal、medium、xhigh、max：Chat/Responses 均成功；Anthropic 验证 medium、xhigh、max，minimal 按本地契约不提供。
- Chat/Responses 的 effort=none、Anthropic thinking=disabled：流式返回正常，响应不再包含思考内容/项目/块。
- 三条真实工具往返：模型产生一个完整 LiveProbe 调用，测试器构造对应 tool result，再由模型返回正确验证字符串；没有丢失工具调用 ID、参数、推理续传状态。
- Anthropic 响应中的 thinking 块从真实流式/非流式响应中保存；后续工具结果请求成功回传这些块。
- Responses reasoning.summary=auto、Anthropic thinking=enabled/budget_tokens=2048：请求被接受并完整响应。参数的服务端效果限制见下节。
- 使用当前 Rust 网关实际 dispatch 和适配器，不使用另一套 HTTP 请求实现绕过 Runtime 代码。
- 此前本地 Runtime 配置验证覆盖注册、公开回读、持久化后的宿主显式重载及非法配置拒绝；工作区测试通过。随后补充的行式工具历史签名保留测试、全部 AI Assistant/Gateway 测试通过。
- Lit 类型检查、74 项测试及构建通过；编辑器保存测试覆盖新模型推理强度及其他模型已有配置的保留。

## 验收边界

本次只有 DeepSeek 实际凭据；“三种范式通过”指 DeepSeek 的三个官方兼容端点，不代表 OpenAI/Anthropic 原厂或所有第三方代理都已实测。

DeepSeek 官方文档明确：
- reasoning_effort 的部分枚举会映射到同一实际档位，因此请求成功不证明每一档都有独立效果。
- Anthropic 兼容 thinking.budget_tokens 被忽略。本次仅确认配置编码、本地预算约束和接口接受，未验证 Claude 原厂的固定预算执行。
- Responses reasoning.summary 被接受但不生成摘要。本次仅确认接口接受，未验证 OpenAI 原厂摘要生成。
- 本次简单题用于参数/协议回归，不作为推理质量、成本或延迟对比基准；Chat 流式返回中部分 token usage 缺失，不据此估算费用。

## 可重复验收

新增 ai-gateway/tests/live_reasoning.rs，默认 ignored，不会在日常测试中消耗真实 API。显式设置 RUNTIME_REASONING_LIVE_CONFIG（宿主配置路径）、RUNTIME_REASONING_LIVE_REPORT（无敏感内容的输出路径），再运行该 ignored 测试。RUNTIME_REASONING_LIVE_PHASE=extended 只执行额外档位及关闭思考验收；默认执行核心流式/非流式、工具往返和附加字段。

本机脱敏结果位于 target/reasoning-live-results.json 和 target/reasoning-live-extended-results.json；未纳入发布包。

## Engineering Review

Architecture: 仍只使用三个范式；模型配置经真实 dispatch 进入对应适配器，不增加厂商专用编码分支。
Code: 真实验收复用正式请求、解析和历史续传代码；新增测试默认跳过且不包含凭据。
Concurrency: 推理参数按模型 UID 显式传递；此前同名模型的并发隔离测试通过，本次真实请求按序执行。
Resource: 验收限于 41 个小请求，单次受超时约束，工具为本地固定返回值，无业务写入。
Audit: 保留场景、范式、耗时、完成原因、公开 token 用量和思考内容长度；不记录 key 或原始思考。
Verification: 38/38 场景通过；本地工作区、网关、AI Assistant、配置链路及 Lit 检查通过。

Risks: 原厂 OpenAI/Anthropic 尚未实测；兼容服务忽略字段不能被请求成功消除；正式版仍需重建双平台包并核对 SDK 哈希、标签及远程附件。
