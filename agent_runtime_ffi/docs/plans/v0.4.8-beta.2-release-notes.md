# v0.4.8-beta.2 — Native FC streaming compatibility

This beta hardens native function-calling interoperability and includes the
workflow resource improvements developed after `v0.4.8-beta.1`.

## Fixed

- Preserve the first non-empty OpenAI-compatible streaming tool call ID when
  later argument chunks contain `id: ""`.
- Preserve the first non-empty tool name when later chunks contain an empty
  name.
- Reject conflicting non-empty tool call IDs for the same stream index before
  any tool result can be paired with the wrong call.
- Expose per-endpoint `to_ai_max_chars` in `resources.json`. The compatibility
  default remains 600 characters, while `0` disables character truncation for
  RPC `to_ai` text and string fields summarized from `result`.

## Added

- Registered workflow reference nodes and invocation scripts.
- Unified workflow script and blueprint revision handling.

## Verification

- Regression coverage models both empty-ID continuation chunks and conflicting
  non-empty IDs.
- Native Runtime archives and SDK checksums are produced by the formal release
  preparation workflow.
