# v0.5.0-beta.1 控件交互更新报告

- 仓库：https://github.com/kouryu339/orbit-runtime
- 开发分支：jiangrong/multimodal-model-support
- 发布：覆盖 v0.5.0-beta.1 预发布；不合入 main。

## 修改范围

| 部分 | 修改 |
|---|---|
| Runtime / Think | 删除旧 Asking 模板与未调用的格式化函数，保留 ViewPayload、多元交互标识和现有 ASK 解析；去掉日期、时间控件指导。 |
| Lit 解析 | 保留确认/取消、单选、多选、路径、文本五类控件。 |
| Lit 选择控件 | 程序自动补充始终可见的“其他”输入；单选允许自由替换，多选允许推荐项与自定义内容组合。 |
| Lit 样式 | 整行颜色表示选中，保留原生键盘选择语义；确认/取消居中分开；文本、路径输入适配窄容器。 |
| Lit 提交 | 整条消息底部只有一个提交按钮，汇总所有控件段已就绪的值，输出普通用户消息。 |
| Lit 生命周期 | 提交后禁用整条消息控件；出现后续用户或 AI 消息后旧控件失效。保留历史答案，以灰色及“已提交/已过期”文字显示。 |
| 预览与契约 | 新增 widgets.html 预览，更新中英文宿主契约及发布说明。 |
| 发布元数据 | Windows/Linux 重建，同步清单和 Rust、Go、Python SDK 的下载哈希。 |

## Engineering Review

Architecture: Runtime 负责控件指导；Lit 负责渲染、补充自由输入、汇总提交和显示生命周期。
Code: 控件保持原位置，提交入口提升到消息末尾；移除旧模板及日期/时间分支。
Concurrency: 提交入口同步锁定本消息，避免重复发送；后续消息使旧控件禁用。
Resource: 无新增轮询或网络请求；沿用现有消息发送通道。
Audit: 结果仍为普通用户消息，发布资产与 SDK 哈希保持一致。
Verification: 上述检查通过；远程分支、标签、发布资产由发布后 API 核验。

Risks: Linux 动态加载及自动视觉复核未执行；覆盖同名 Beta.1 需刷新旧包缓存。
Decisions Needed: 无。
