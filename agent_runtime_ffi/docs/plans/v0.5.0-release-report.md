# Orbit Runtime v0.5.0 正式发布核验

日期：2026-10-12（Asia/Shanghai）。仓库：https://github.com/kouryu339/orbit-runtime。
正式落点：main；发布标签：v0.5.0；原生 ABI：1.3。

## 修改范围

正式版包含从 v0.4.8 以来开发分支的图片输入、剪贴板粘贴和文字内图片引用，View 五类控件及整条消息统一提交/过期状态，工具紧凑目录及 ToolDescribe，GrepJson 的结构读取/分页/revision 校验，宿主决定 Skill 激活与检索工具开放，以及最后新增的模型推理配置。

推理设置保存在每个模型的 reasoning 中，只按 Chat Completions、Responses、Anthropic Messages 三种范式编码；Lit 显示对应配置字段。Anthropic 思考块保存和回传覆盖原生工具与行式工具历史。未配置时维持既有行为。

Runtime FFI、Rust Runtime SDK、Python SDK 包和各语言原生下载元数据已切换为 0.5.0。当前 SDK 文档指向 v0.5.0；历史 Beta 报告保留为验收记录。

## 验证

- Rust 格式检查、工作区串行测试通过；Runtime 137 项、AI Assistant 348 项测试及 JSON 验收、Gateway/SDK/文档测试通过，原有标记跳过项保持跳过。
- Lit 类型检查、74 项测试、构建通过。
- Go SDK 检查、C++17 示例语法编译、Python SDK 元数据和源文件语法检查通过。
- 真实 DeepSeek 三个官方兼容端点验收：38 个场景、41 次请求，0 失败，覆盖各档位、关闭思考、流式/非流式及工具往返。
- Windows DLL 实际加载、版本 0.5.0、ABI 1.3、注册、启动、模型推理设置公开回读、GrepJson 工具目录、关闭和销毁通过。
- Linux x86_64 交叉编译、链接、ELF 格式和打包检查通过；没有执行 Linux 动态加载。
- 两个平台 ZIP 内原生库和头文件与构建输出一致；SHA-256 与 SDK 清单及 Rust/Go/Python 下载记录一致。
- 正式发布时核对远程 main、开发分支、v0.5.0 标签与同一提交，以及四个远程附件的大小/摘要、稳定发布及 Latest 状态。正式版验证成功后才删除 v0.5.0-beta.1 发布及标签。

## 宿主升级

1. 从 v0.5.0 下载对应平台原生包，同步 SDK 元数据及 Lit dist，重启 Runtime；不要复用 Beta 包。
2. Grep/GrepJson、GetSkillsList/UpdateSkills、Jev 工具不会由默认 Think 自动开放；宿主按业务 Skill 显式提供。GrepJson 仍需配置授权根，修改由宿主工具负责版本校验与原子写入。
3. 可为 enabled_models 中的每个模型添加 reasoning。各兼容端点是否支持具体档位/附加字段，以其实际能力为准。DeepSeek 接受但忽略固定预算，接受 Responses summary 但不生成摘要。
4. 本次正式发布不改变 ABI 主版本，也不改写宿主已有 provider/资源配置。

## Engineering Review

Architecture: 保留三个 API 范式，宿主负责能力开放和写入；正式代码落在 main。
Code: 复用既有配置、请求、历史与事件通道；版本、包、SDK 元数据一致。
Concurrency: 模型推理配置按 UID 隔离；历史/工具往返与同名模型并发验证通过。
Resource: 输入、输出、JSON 解析受限；真实验收只用小请求和无业务副作用的测试工具。
Audit: 版本、SHA-256、ABI、真实场景计数及发布引用可核对；凭据不进入源码/附件。
Verification: 工作区、Lit、SDK、Windows 运行及双平台包核验通过；远程发布完成后实时验证。

Risks: Linux 动态加载及 OpenAI/Anthropic 原厂未实测；兼容接口成功不保证其忽略的字段实际生效。
Decisions Needed: 无。
