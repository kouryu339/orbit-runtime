# Orbit Runtime v0.5.0-beta.1 — Image input

This prerelease adds image input to agent conversations. It builds on v0.4.8 and keeps native ABI 1.3.

## Changes

- Hosts import local PNG, JPEG, WebP, or GIF files with `conversation.import_image`, then send ordered text and image parts through `conversation.send_message`.
- Runtime owns copied conversation media, validates file type, dimensions, size, and content hash, and restores image references with the conversation ledger.
- OpenAI Chat Completions, OpenAI Responses, and Anthropic-compatible requests encode image parts in their respective provider formats.
- Rust, Python, Go, and C++ Runtime SDKs expose the image import operation.
- Diagnostics avoid logging embedded image data. History summaries retain image references without inventing visual descriptions.
- Lit accepts selected and pasted images, inserts `@图片1` references at the cursor, and sends ordered text/image parts. Messages render references inline with stable object-based colors.
- Pending image messages retain ordered parts and reconcile with the Runtime ledger without a separate image-count bubble.
- `ListJev` and `RunJev` are removed from the default `thinking` and `thinking-pro` skill tool lists. Jev implementations and host APIs remain available for explicit integration.

## Widget interaction refresh

- Think keeps inline View widgets and their identifiers. Only the obsolete Asking prompt templates and their unused formatting helper are removed.
- Supported controls are confirmation/cancellation, single choice, multiple choice, file path, and text input. Date/time controls are removed from the Runtime guidance and Lit parser.
- Lit automatically adds an always-visible Other text input to single/multiple choices. Models should provide recommended options only.
- Choices use whole-row colors for selection; confirmation/cancellation buttons are centered, and text/path inputs fit narrow layouts.
- Every assistant message has one final submit action that collects ready values from all widget groups, including groups separated by explanations or blank lines.
- Submission disables every control in that message. A newer user or assistant message expires old controls; saved answers remain visible, with muted selection styles and a plain Submitted/Expired status.
- A local widget preview page is included at ui/lit/playground/widgets.html.

## Scope and distribution

Image input only: audio, video, and generated image output are not included. Hosts provide Lit's image importer, pass host-accessible image paths to Runtime, and forward `SendMessageRequest.parts` unchanged. Windows x86_64 and Linux x86_64 native archives are provided. No macOS archive is available from this release machine.

This replaces the earlier Beta.1 archives. Replace the native library and matching SDK release metadata together, update Lit, then restart the Runtime to load the revised built-in skills. Live provider compatibility still depends on the configured model and provider accepting image input. This update does not claim to fix host-side sending or event blocking.
