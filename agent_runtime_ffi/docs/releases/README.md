目录约定：

- 正式更新说明：`<version>/release-notes.md`。
- 正式版本更新与验收报告：`<version>/release-report.md`。
- 报告标题和开头明确上一个正式版本及两个发布标签。
- 中间 Beta 说明、临时打包报告和重复的专项验收不在这里累积；必要结论合并到对应正式报告。
