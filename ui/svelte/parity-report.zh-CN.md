# Svelte 与 Lit 前端对齐

分支：`jiangrong/lit-svelte-frontend`。基准：当前 `main` 的 Lit 实现（`60eb2a6`）。

Svelte 保持原生组件渲染，复用 Lit 包的无框架协议、宿主接口、消息投影和内容规则；没有嵌入 Lit 自定义元素。本轮不涉及 Runtime、FFI 或工作流分支的修改。

## 对齐范围

| 能力 | 实现与验证 |
|---|---|
| 图片输入 | 选择、剪贴板粘贴、光标插入、标记重排、文件与数量限制、顺序导入、图片单独发送、失败保留、切换与卸载释放预览 |
| 消息投影 | 共用 `conversation-view.ts`；普通消息、工具占位、流式消息、网关错误、展示项插入顺序和定位一致 |
| 内容交互 | 共用 Markdown、公式、内容解析与渐进显示规则；选择题“其他”、多选、确认/取消、单次聚合提交及过期状态 |
| 执行计划 | 原生 Svelte 卡片；步骤状态和进度、折叠保持、旧 Markdown 计划回退、文本转义 |
| 审批 | 安全目标摘要、多请求、隐藏工具后审批仍可见、终态拒绝清理、Runtime 终态事件同步、失败可重试 |
| 模型与厂商 | 会话模型选择、厂商新增/编辑、保留其他模型及 reasoning、推理强度、Responses 摘要、Anthropic 模式与预算 |
| 历史会话 | 宿主持久化、订阅更新/移除/绑定变化、后台状态、打开、保存方法、失败事件及旧异步响应隔离；保存不作为默认头部按钮 |
| 外观与嵌入 | Lit 默认主题、密度、配色和文案；四种插槽；组件自带作用域样式，宿主无需引用演示页全局 CSS |
| 对外接口 | 共享公共方法清单、同名事件、Svelte `bind:this` 状态访问；根入口重导出共享接口与工具 |

Svelte 原有的首条消息等待权威快照及取消行为保留。原有 `dark`、`baseDir` 内容属性保留，同时支持 Lit 的 `colorScheme`、`contentBaseDir`、`contentMetadata`。

## 防止后续漂移

- `ui/sync-svelte-styles.mjs` 从 Lit 会话、富内容、计划和 Mermaid 样式生成 Svelte 作用域 CSS，`npm run check:styles` 检查一致性。
- 两个实现共用消息排序、展示项定位、Widget 过期判断和渐进显示辅助函数；Lit 原有行为由其测试继续保护。
- `tests/parity.test.ts` 挂载真实 Lit 与 Svelte 组件，对比代表性消息投影，并覆盖新增交互；不是仅检查功能列表中的声明。
- 测试使用 jsdom，验证 Markdown 净化、公式以及图片/链接宿主回调。生产代码继续使用原有 DOMPurify 方案。

## 验证结果

Lit 74 项测试、Svelte 24 项测试通过；两套类型检查和构建通过，Svelte 类型检查为 0 错误、0 警告。样式同步检查及 `git diff --check` 通过。前端机械检查未报告问题。

浏览器首轮检查覆盖桌面空态和输入发送。后续本地浏览器控制被当前应用设置停用，因此没有完成最终桌面/移动视口及逐像素视觉对照；不能将代码与样式对齐称为已完成全量视觉回归。验证没有连接真实 LLM、宿主持久化服务或业务工具。

## Engineering Review

Architecture: 无框架契约与状态投影共享，两套渲染保持独立；没有通过包装 Lit 代替 Svelte。

Code: 提取现有规则并补齐 Svelte；生成样式有明确来源和检查命令；组件与测试已格式化。

Concurrency: 会话连接有代次与取消信号；图片导入、审批、模型选择及会话保存/打开/关闭防止旧响应覆盖当前状态。

Resource: 图片格式、大小与数量受限，预览和订阅在切换/卸载时释放；渐进显示按线性投影处理，Mermaid 按需加载。

Audit: 公共事件保留操作结果，错误可定位到导入、模型、审批或持久化操作；审批只展示安全字段。

Verification: 98 项测试、两套类型检查及构建、样式同步和差异检查通过。

Risks: 最终浏览器视觉回归及真实宿主联调未完成；Mermaid 图表依赖仍有较大的构建分块告警。

Decisions Needed: 无。
