# 前端验收

- Lit：http://127.0.0.1:1420/
- Svelte：http://127.0.0.1:1421/

两页使用同一份 `acceptance.ts` 模拟宿主和场景，渲染分别使用真实 Lit、Svelte 组件。模型、工具、图片导入和历史存储不连接 Runtime 或真实业务服务。厂商配置及归档保存在当前页面内存中，刷新即重置；不要输入真实密钥。

## 验收入口

1. **完整展示**：Markdown、表格、代码、引用、公式、Mermaid、图片缩略图及预览、执行计划、六种工具状态、完整交互表单，默认直接展示。
2. **交互表单**：单选、多选、自定义“其他”、文本、文件路径、确认和取消，一次提交。
3. **多工具审批**：工具展开、多个审批、安全目标摘要、允许/拒绝及审批过期。
4. **流式回复**：自动开始流式输出，可暂停；也可在任一空闲会话发送消息体验。
5. **执行计划**：折叠计划、点击“推进计划”，检查进度及折叠状态。
6. **异常与重试**：模型错误、中断；“下次发送失败”“下次图片失败”用于检查失败后的输入保留。
7. **空会话**：检查空态、输入与发送。
8. **工具状态**：请求执行、执行中、等待批准、成功、失败、结果待确认；展开只显示用户摘要或状态说明，待批准示例可允许或拒绝。

会话头部可新增厂商、新建及切换历史会话；模型与厂商管理入口位于输入区右侧。验收栏可保存会话、插入渐进预设、查看总结状态、关闭和重新连接。图片可通过输入框旁按钮或剪贴板加入。主题、配色、密度、语言、隐藏工具和渐进显示开关可对照测试。

输入区左侧为图片和权限，右侧为模型、推理强度及主按钮。右侧菜单可选择模型、调整当前会话的推理强度、重置默认值，并进入厂商管理；左侧菜单可切换模拟权限模式。切换“流式回复”后点击暂停，等待停止后显示继续；新输入会把主按钮切回发送。发送中、暂停中、继续中、整理上下文和断线时均禁用不适用的操作。

验收页默认使用 `white` 白色主题。操作栏位于输入框底部；空闲时不保留状态占位，运行状态显示在操作栏上方。

推理强度滑块在拖动过程中实时预览档位与无障碍描述，松手后提交一次；失败后恢复已确认值。顶部栏采用“对话＋连接状态”和统一线条图标，历史入口明确标为“历史会话”。

厂商弹窗采用固定标题、配置方式切换、独立滚动区和固定操作栏。手动配置与 JSON 导入分开，选择文件只载入候选内容，提交后才调用宿主。支持焦点约束、Escape 关闭与焦点返回；保存中禁止重复提交和关闭，失败保留候选。两套前端共用校验和预设选择逻辑。

“浏览…”的路径选择返回固定模拟路径；图表由实际 Mermaid 渲染。模拟厂商仅检验前端编辑与回读，不能替代 Runtime 及上游参数校验。

## 启动

分别在两个目录运行：

```powershell
# ui/lit
node node_modules/vite/bin/vite.js --config playground/vite.config.ts --host 127.0.0.1 --port 1420 --strictPort

# ui/svelte
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 1421 --strictPort
```

## Engineering Review

Architecture: 共用宿主契约、状态机、厂商校验和模态交互；两套渲染保持独立，不改 Runtime 核心。

Code: 厂商弹窗结构和操作一致；样式生成器隔离子组件，避免 Svelte 的父级按钮样式覆盖控件边框与颜色。未接入的宿主能力禁用。

Concurrency: 模态保存期间锁定交互并拦截重复提交；关闭或重新打开后忽略旧文件读取结果。暂停等待确认，切换会话后忽略旧回读。

Resource: 模态事件监听在卸载时移除、恢复背景状态；配置保存在演示页内存，图片 URL 回收，操作记录最多 40 条。

Audit: 页面明确标注模拟范围，操作与失败有记录，不回显密钥。

Verification: Lit 85 项、Svelte 51 项测试、类型检查、样式同步及构建通过。包含工具原文与命令不进入卡片 DOM 的测试；浏览器检查工具展开只展示用户说明。

Risks: 工具原文不在卡片展示，但可能仍随传输或 ledger 到达前端；真实宿主负责数据访问权限、用户摘要及配置验证。演示页使用内存模拟。Mermaid 构建存在大分块提示。

Decisions Needed: 无。
